# CraftGuide

A phone-first Minecraft: Java Edition guide (crafting, enchanting planner, brewing, villager trades, smithing and armor trims, banners, food, and tools for Nether portals, XP and furnace fuel). Plain HTML, CSS and JavaScript with no build step. Live at https://craftguide-blue.vercel.app

- `site/` is the whole website. Open `site/index.html` through a local server, for example `cd site && python3 -m http.server`.
- Deployed on Vercel from this repo (`vercel.json` publishes `site/`). The older Netlify copy at https://craftguide.netlify.app also still deploys (`netlify.toml`).

See `CLAUDE.md` for how everything works.
