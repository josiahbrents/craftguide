# Minecraft companion

A phone-first Minecraft: Java Edition guide (crafting, enchanting planner, brewing, villager trades, smelting, smithing and armor trims, banners, food, XP and Nether portals). Plain HTML, CSS and JavaScript with no build step.

- `site/` is the whole website. Open `site/index.html` through a local server, for example `cd site && python3 -m http.server`.
- Deployed on Netlify from this repo (`netlify.toml` publishes `site/`).
- Keep this repository private: `site/` contains Mojang's textures and font.

See `CLAUDE.md` for how everything works.
